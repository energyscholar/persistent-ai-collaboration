# Your AI Has Amnesia

A practitioner's guide to building persistent AI collaboration systems.

This document makes zero numeric productivity claims. Instead it demonstrates capability through artifacts: the document itself, and two standalone tutorials produced by the same system.

**Read it:** [energyscholar.github.io/persistent-ai-collaboration](https://energyscholar.github.io/persistent-ai-collaboration/)

## What's here

- `index.html` — the guide (standalone, no external dependencies)
- `tutorial-magnetosphere.html` — cinematic space physics tutorial (multi-pass production)
- `tutorial-inference.html` — LLM inference walkthrough (single-pass production)

## The approach

Three boundary conditions — execution governance, truth governance, continuity governance — that prevent the specific failure modes which make sustained AI collaboration unreliable. Replication guide included: start in 15 minutes, build over a weekend.
