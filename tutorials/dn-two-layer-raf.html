Dignity Net — Two-Layer RAF

Resilience analysis of Genevieve Prentice's governance architecture using Kauffman's autocatalytic set theory. A modeling refinement — not a revision of DN itself.

1. Quick RAF Recap

A Reflexively Autocatalytic and Food-generated (RAF) set is a set of reactions where:
(1) every reactant is either in the food set or produced by another reaction in the set, and
(2) every reaction is catalyzed by something in the set or the food set.

A system with RAF structure is self-sustaining — it maintains itself from available resources without external direction.

The original DN RAF model used a flat food set {embodied existence, recognition, communication, empathy} and showed that DN's 8 components form an autocatalytic network. But that model treated DN's ontology — the three foundational recognitions in Layer I of the spec — as background. Gen asked: what if the ontology is itself autocatalytic?

4. Three Relationship Types

Type 1 — Intra-layer catalysis (Layer 0 cycle): O1 → O2 → O3 → O1. The ontology sustains itself.
Type 2 — Cross-layer catalysis (11 connections): Each ontological recognition enables specific ethical reactions. "X is necessary for this principle to function."

O1 (Body): Mirror, Lightly, Integrity, Storm
O2 (Ambiguity): Mirror, Corners, Storm
O3 (Interdependence): Mirror, Corners, Lightly, Web
Type 3 — Ontological constraints (5 connections): "X doesn't enable this reaction, but without X the product degrades." The component still functions, but its quality changes.

O2 → Diagnostic: Without ambiguity tolerance, detection defaults to premature closure and binary pattern matching.
O1 → Governance: Without embodiment, proportionality becomes abstract rule-following.
O3 → Governance: Without interdependence, escalation ignores web effects.
O2 → Governance: Without ambiguity, graduated levels (L0–L5) collapse toward binary comply/refuse.
O3 → Integrity: Without interdependence, integrity becomes mere self-consistency rather than accounting for downstream effects.
The distinction matters: In RAF terms, catalysis says "X enables the reaction." A constraint says "X determines the quality of the product." Both are structurally present. Both appear in the diagram. But they predict different failure modes: losing a catalyst stops the reaction; losing a constraint degrades its output.

The outer-shell problem dissolves. In the original model, Storm had only 2 catalysts, both from outer-shell components (Corners and Lightly, themselves only 2 each). The system's fragile point was three layers deep. In the two-layer model, every ethical principle draws from the ontological bedrock. There are no chains of single-sourced dependencies.

6. The AI Case — Remove O1

The most revealing test: what happens to a system running DN without embodiment?

The predicted failure mode: Without O1 (embodiment), Integrity drops from 3 catalysts to 2 — becoming the system's most exposed ethical principle. The math predicts: an AI running DN without embodiment can still mirror, still leave corners, still protect the web — but "choose integrity over cleverness" loses its embodied root.

Gen's correction (important): This does not mean the system "performs ethics without being ethical." Compassion often builds from practice. Ethical form is not fake merely because it begins as discipline. The distinction is procedural ethical form versus embodied ethical grounding. For AI, the open question is whether repeated ethical form can ever become participation — or whether it remains alignment without lived stake. The math identifies the structural gap; it does not answer whether practice can bridge it.

7. Near-Optimal Design

Is the current DN configuration at or near the resilience sweet spot?

What "sweet spot" means in RAF terms

An optimal RAF has:

  • No single-catalyst components — every reaction survives the loss of any one catalyst
  • Multiple independent catalyst sources — not all catalysts from the same chain
  • Self-sustaining food generation — the food set is always available
  • Graceful degradation — losing a component reduces quality before stopping function

DN's scorecard

CriterionStatusDetail
No single-catalyst components PASS Minimum is 2 (Diagnostic). All ethical principles ≥ 3.
Independent sources PASS Every component draws from at least 2 of {O1, O2, O3, intra-layer}. No single-chain dependencies.
Self-sustaining food PASS Layer 0 food set (lived experience, plurality, relation) is always available to embodied beings.
Graceful degradation PASS The constraint layer creates quality degradation paths distinct from catalytic failure. System dims before it breaks.
Not over-connected PASS 16 cross-layer connections out of 24 possible (67%). Rich but not saturated — room for components to have distinct characters.
Result: The two-layer model reveals that DN, as originally designed, was already close to the resilience sweet spot. The ontological layer was implicit in the spec — making it explicit in the model fills the structural gaps (Storm's fragility, the outer-shell problem) without adding new principles. The design is near-optimal because the three ontological recognitions are genuinely independent and each connects to a distinct subset of ethical principles.

What would make it better? Not much. Diagnostic could gain a direct catalyst (not just a constraint from O2), but its operational nature — detecting divergence — is appropriately lean. Governance's triple-constraint from all three ontological roots is structurally correct for the component that decides action. Mirror's 6 catalysts make it the hub, which matches its role: accurate perception is the foundation everything else depends on.
